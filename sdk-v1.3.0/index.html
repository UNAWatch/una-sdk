UNA Watch Documentation

Welcome to the official UNA Watch SDK documentation hub. This platform enables developers to create high-performance applications for the UNA Watch ecosystem.

The SDK includes tutorials to guide you through creating your own apps for the watch, as well as comprehensive documentation of the pre-made apps on the watch.

Getting Started

First, please follow the SDK Setup and Build Overview to download and install the SDK for your operating system.

Next steps:

Platform Overview - For an overview of the UNA Watch platform’s unique architecture and capabilities.

Tutorials - For step-by-step guides for building different watch apps, increasing in complexity.

Running - Fitness Tracking to dive right into the code of pre-made watch Apps.
