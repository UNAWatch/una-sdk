# UNA Watch reference applications

Open-source example and reference apps for the UNA Watch SDK live in `Examples/Apps/`.

## Contributing

- Clone [una-sdk](https://github.com/UNAWatch/una-sdk) (this directory is part of that repository).
- Make changes under `Examples/Apps/<YourApp>/`.
- Open a pull request against [una-sdk](https://github.com/UNAWatch/una-sdk).

## Releases

Apps releases are tagged in una-sdk with the `apps-v*` prefix (for example `apps-v0.2.0`). SDK releases use the `sdk-v*` prefix.

The former [una-apps](https://github.com/UNAWatch/una-apps) repository has been merged into una-sdk; use una-sdk for all new work.
