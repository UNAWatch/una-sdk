# UNA Watch UI Resource Pack (Penpot)

`UNA-Watch-UI-Resource-Pack.penpot` is the [Figma UI Resource Pack](../Figma-UI-Kit/README.md)
converted for [Penpot](https://penpot.app), a free, open-source design tool. It carries the
same pages: the watch mockups, the round screen frame with the four button labels in place,
brand assets, and the UI elements the built-in apps are drawn from.

To open it: sign in to Penpot (a free account is enough), open the projects menu, choose
**Import files**, and pick the `.penpot` file.

Usage notes, including how to take a screen from the design to the TouchGFX Designer, are in
[`Docs/figma-ui-kit.rst`](../../figma-ui-kit.rst).

Converted from Figma pack version 1.0 with the Penpot Exporter plugin
(`penpot-exporter-figma-plugin` 0.25.0). This is a design reference only — no part of the
firmware or app build reads this file.
