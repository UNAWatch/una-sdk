# UNA Watch UI Resource Pack (Figma)

`UNA-Watch-UI-Resource-Pack.fig` is the design source used for the UNA Watch
GUI. It carries the watch mockups, the round screen frame with the four button
labels in place, brand assets, and the UI elements the built-in apps are drawn
from — so a third-party app can be laid out to look native next to the
pre-installed ones.

To open it: **Figma -> File browser -> Import**, or drag the `.fig` onto an open
Figma project. Nothing beyond a free Figma account is needed.

Usage notes, including how to export screen assets in the form the TouchGFX
Designer expects, are in [`Docs/figma-ui-kit.rst`](../../figma-ui-kit.rst) —
published as *Figma UI Resource Pack* on
<https://www.developers.unawatch.com/>.

Pack version 1.0, exported August 2026. This is a design reference only — no
part of the firmware or app build reads this file.
