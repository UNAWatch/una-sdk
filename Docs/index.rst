UNA Watch Documentation
===========================

Welcome to the official UNA Watch SDK documentation hub. This platform enables developers to create high-performance applications for the UNA Watch ecosystem.

The SDK includes tutorials to guide you through creating your own apps for the watch, as well as comprehensive documentation of the pre-made apps on the watch.

Getting Started
---------------
First, please follow the `SDK Setup and Build Overview <https://www.developers.unawatch.com/latest/sdk-setup.html>`_ to download and install the SDK for your operating system.


Next steps:
^^^^^^^^^^^

`Platform Overview <https://www.developers.unawatch.com/latest/platform-overview.html>`_ - For an overview of the UNA Watch platform's unique architecture and capabilities.

`Tutorials <https://www.developers.unawatch.com/latest/Tutorials/HelloWorld/ARCHITECTURE.html>`_ - For step-by-step guides for building different watch apps, increasing in complexity.

`Running - Fitness Tracking <https://www.developers.unawatch.com/latest/Examples/Running-Architecture.html>`_ to dive right into the code of pre-made watch Apps.
